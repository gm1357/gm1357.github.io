# gm1357.github.io

Personal portfolio website for Gabriel Machado.

## Tech Stack

- React 19
- Vite 7
- Tailwind CSS 4
- React Router DOM

## Features

- **Home** — Introduction and social links
- **Resume** — Professional experience and skills
- **Portfolio** — Projects with dynamic GitHub integration

## Getting Started

```bash
npm install
npm run dev
```

### Available Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server |
| `npm run build` | Build for production |
| `npm run preview` | Preview production build |
| `npm run lint` | Run ESLint |

## Deployment

Auto-deployed to GitHub Pages on push to `master` via GitHub Actions.
